# Isha Talegaonkar — Portfolio

Static personal site (About, Resume, Blog) served with GitHub Pages. No build step.

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Push to a repo named `isha-talegaonkar.github.io` (or any repo with Pages enabled on the `main` branch, root folder).
